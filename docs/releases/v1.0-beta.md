# RSAI v1.0.0-beta — Release Notes

**Release Date:** 2026-07-26  
**Version:** 1.0.0-beta  
**Status:** Baseline Release

---

## Overview

RSAI v1.0 Beta establishes the production baseline of the Resume Studio AI platform. This release completes the PostgreSQL migration, Administration Console, CI/CD pipeline, enterprise authentication hardening, and user management system.

## What's New

### PostgreSQL Migration (Complete)
- 15 database tables with full FK/index/constraint coverage
- 6 Alembic migrations from initial schema through audit logging
- Dual-engine architecture (async + sync SQLAlchemy) matching FastAPI's async nature
- Data migration utility with dry-run, validation, and per-entity migration
- PostgreSQL-only production mode with startup enforcement
- 14 repository implementations covering the complete data model

### Administration Console
- 12 admin API endpoints covering dashboard, AI, database, storage, features, system health
- AI configuration page with model selection, connection testing, and model discovery
- Database diagnostics with validation runner (FK integrity, table counts, connection)
- Storage management with PostgreSQL status and JSON file counts
- Feature flag toggles (runtime with restart advisory)
- System health aggregated view with colour-coded status cards
- Configuration diagnostics (JWT, DB, AI, storage, environment) — never exposes secrets

### Enterprise Security
- JWT secret enforcement (32+ char minimum, production startup fails without it)
- Development mode consolidation with `DevelopmentFeatures` service
- Mock authentication requires explicit DEBUG mode
- Invalid JWTs never produce mock users
- Admin bootstrap script for secure admin user creation
- Admin role management with self-demotion and last-admin protection
- Password policy (12+ chars, mixed case, digits, special)
- Temporary password generation with must-change-password flow
- Custom password option for admin password resets
- Immutable audit logging for all administrative actions

### CI/CD & Quality
- GitHub Actions CI: code quality, JSON tests, PostgreSQL tests, DB validation, smoke tests
- GitHub Actions Release: pre-release checks, full validation, auto-release notes
- Ruff linting and formatting
- Production deployment scripts (deploy, rollback, backup, smoke_test)
- Docker Compose for PostgreSQL 16

### User Management
- Admin Users page with search, role filter, pagination
- User details dialog with full profile information
- Disable/enable, promote/demote with confirmation dialogs
- Password reset with system-generated or custom passwords
- User profile page with Security tab for password changes
- Login integration: must-change-password flag triggers forced password change

## Deployment

```bash
# Prerequisites
PostgreSQL 16+, Python 3.12+, Node.js 20+

# Backend
cd backend
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --port 8000

# Frontend
cd frontend
npm install
npm run dev
```

## Rollback

```bash
# Quick rollback to JSON
cd backend
bash scripts/deployment/rollback.sh
# Restart application
```
